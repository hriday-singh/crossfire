# 🚀 Crossfire (Frontend)

[![Powered by SerpApi](https://img.shields.io/badge/Search%20Grounding-Powered%20by%20SerpApi-377FEA?style=flat&logoColor=white)](https://serpapi.com)

## Overview
Crossfire frontend application built with React, Vite, and Tailwind CSS. Provides the interactive decision proposal entry canvas, real-time claim extraction review, and SSE-driven live adversarial stress-testing dashboard.

**Evidence Grounding:** Live search verification and evidence citations are powered by [SerpApi](https://serpapi.com), displaying real-time web results and contradiction tracing for every tested assumption.

## Tech Stack & Core Libraries
* **Framework:** React 18 (TypeScript) + Vite
* **Styling & UI:** Tailwind CSS, Radix UI primitives, Custom token system
* **Live Search & Evidence Grounding:** [SerpApi](https://serpapi.com)
* **Icons:** SerpApi brand vector icon, Material Symbols Outlined
